# DSH Web 学生端适配

基于小智伴学 2.12.5，源提交 `c6d628d0602d16585be31abb17bfc4ea0c725b01`。
适配版本 `dsh-web-2`，保留上游作者、MIT 许可与学科资源。

## 构建

使用 Python 3.10+ 标准库，无需安装开发依赖：

```text
python scripts/build-dsh.py --output <源码目录外的新输出目录>
```

输出为 49 个学生技能的平铺目录、文件哈希清单和 tar.gz 归档。filesystem provider
只扫描技能根直接子目录，不能直接复制上游多层 student 目录。老师端和开发者工具不进入包。
各技能保留完整 references、shared、schema 和许可。唯一 JS 资源 schemas/validate.js
是按哈希固定的上游开发期校验示例，仅复制而不执行，不安装其开发依赖。

## 运行行为

- 直接使用会话中实际可用的图片理解能力，不绑定模型厂商和型号。
- 补充技能加载、引用路径、题目条件确认与可用 Office 工具的衔接约定。
- 不修改上游教学正文。学习 DNA 与 IM 提醒仅允许用户调用，其余 47 个保留模型调用。
- 包内不实现长期档案、历史统计或主动提醒后端；M/X/T 默认按缺失处理。
- 未提供专用语音、精确计时等能力时使用上游的降级规则。
- 只安装技能资源，不修改应用源码，不安装额外运行依赖，无需重新构建运行镜像。

## 安装与验证

将归档中 skills 的直接子目录安装到 `$DSH_HOME/skills`，保留与本包无关的技能。
更新同名目录前检查已有内容；本地回执与必要备份存放于忽略目录。
使用实际运行版本的官方 FileSystemSkillProvider 检查唯一名称、正文、调用策略和资源可读性，
并核对构建清单的文件哈希。无需为文件技能加载重启应用。

构建清单只记录源码版本、是否有未提交改动与资源哈希；归档不写入本机用户、组和时间戳。
设备、账号、地址、挂载、模型配置、凭据和个人验证记录不得提交；需要保存时使用 `.private/`，
并以 `git check-ignore` 验证。通用文件检查不代替真实题图和教学效果验证。
