# 小智伴学：DSH Web 适配约定

适配版本：`dsh-web-1`；运行基线：DeepSeek Harness `0.2.1-rc.5`。
本文件描述当前 NAS 实例的能力边界，不改变上游学科内容、提示阶梯、授权规则与考试边界。

## 图片与拍照讲题

- 直接阅读当前会话已上传的照片，使用当前模型的原生图片理解能力。MiniMax / GLM 必须选用已经配置图片输入的模型。
- 图片可见时直接读题，不要求另配 OCR、视觉 API Key，不调用其他平台的专属工具。不依赖 agent-photo-question。
- 若只有文件路径，先使用当前会话实际提供的图片读取工具；没有工具、没有附件或模型看不到图时如实说明，改请用户上传图片或提供文字。
- 先确认题号、题干、问题和学生已有步骤；多题且未指定时简短询问题号。数字、正负号、指数、根号、单位或图形标注模糊时先确认。
- 清晰内容不用逐项要求确认；不凭图形比例推断平行、垂直、等长、角度，不把待证明结论当已知条件。
- 年级、教材与已学方法以用户提供信息为准；缺失且影响是否超纲时只问必要问题。无需真实姓名、学校、电话。

## DSH 加载与协作

- 每个技能安装在 `$DSH_HOME/skills/<name>/`，本实例为 `/var/lib/dsh/skills/<name>/`。参考文件相对于当前技能的 resourceBase 读取，不相对于工作区猜路径。
- DSH 按需加载 SKILL.md；`metadata.depends_on` 是描述性信息，不是自动执行器。需要另一个技能时，使用当前会话实际公布的技能加载工具，按准确名字加载；没有加载工具时说明限制，不声称后台交接已经完成。
- 在同一会话沿用已识别题干、学生尝试、确认条件和教学阶段，不让学生重新上传或重复回答。不另开代理，不把图片发给额外服务。
- 直接求讲解先进入对应学科教练；明确做错后按需进入错题本/学科错误 DNA；检查理解时再用费曼。协调器仅负责选路和去重，不代替学科教学。
- 保留上游 L0–L6 提示阶梯及轮次预算，当前步骤已回答则不重复追问；用户要求完整解析时按对应技能上限处理，再用同类题验证。
- 上游提到的平台、接口、JSON 交接与角色名称是教学契约，不证明 DSH 中存在对应工具、接口或角色权限。

## 当前实例能力

| 能力 | 当前处理 |
|---|---|
| O 图片 | 由当前支持图片的模型读取；失败时明确降级为文字输入 |
| F 文件 | 用当前会话实际可用的文件工具；只在用户要求时导出文件 |
| K 日期 | 有可用时间工具时读取当前日期；没有可信日期时询问，不固定日期 |
| M 长期档案 | 本适配未接入具备独立学生身份、字段访问控制的档案服务；只用当前会话 |
| X 历史统计 | 未接入历史数据库；不能编造跨会话正确率、次数、成长曲线 |
| T 主动提醒 | 未接入小智提醒队列/调度/发送服务；只给出待办建议或用户回来时处理当前提供的到期项 |
| A/S/V/C | 未验证专用 ASR、发音评分、TTS、精确计时；按上游统一规则降级 |

- 安装不等于开启建档。`xiaozhi-learning-dna`、`xiaozhi-im-reminder` 只保留用户手动调用；调用时也不得承诺当前没有的服务。
- 不把 Mnemon、聊天历史、文件夹命名或家长/学生的自我声明当身份鉴别与访问控制。不向 Mnemon 写入学生的敏感档案、情绪观察、逐题记录或授权状态。
- 未具备上游要求的隔离和权限前，不创建或读取长期学习档案；即使用户希望记住，也先解释服务缺口。可在当前会话整理摘要，用户明确要求时导出供其自行保存，下次由用户主动提供。
- 周报、月报和计划只能基于当前会话已有或用户明确提供的材料，说明覆盖范围；不得声称遍历了其他会话或统计未提供的数据。
- 没有真实调度工具和成功回执，不说“已入队”“明天提醒你”“我会主动推送”。给用户可复制到手机日历的建议即可。
- 本实例是共享管理员身份，不构成多学生隔离。不收集真实身份或尝试通过提示词补出权限系统。

## 文件与 Office

- 普通讲题直接回复，不因教学会话创建文件或记录。用户要求 Word、PPT、Excel、PDF 时再加载对应已安装的官方 Office 技能。
- 调用已安装的 `load_workspace_dependencies` 获取 Python 环境，不自行安装 Python 包，不重建镜像。
- 输出到当前授权工作区，区分原题、生成练习、解析和答案，遵守 Office 技能的生成、校验与预览流程。
- 当前工作区的未知现有文件不覆盖；删除、更正、导出只针对用户明确指定的内容。

## 验证边界

文件发现、正文加载和引用完整性验证不等于已经验证模型的实际识图、解题或教学效果。
本适配不更改模型、凭据、Compose、DSH 源码、镜像或其他插件配置。
